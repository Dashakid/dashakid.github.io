Process

From a manual task to a system you trust

Same order every time. The safety work happens early, not after something has already gone wrong.

  1. Step 01

    Watch the manual version

    I sit with whoever does the task now and write down every decision they make, including the ones they make without thinking about it.

  2. Step 02

    List what can go wrong

    Before writing features, I write down the failures: bad data, a dead API, a wrong prediction that looks confident. Each one gets a check.

  3. Step 03

    Ship the smallest working loop

    One path from input to output, running on real data on a schedule. It's ugly, but it runs every day.

  4. Step 04

    Add confidence and fallbacks

    Every output gets a score. Low-confidence results go to a person. Failed calls fall back to something safe and log it.

  5. Step 05

    Run it on paper first

    Paper trades, a review queue or a shadow run next to the manual process, until it meets criteria we agreed on up front.

  6. Step 06

    Hand over with eyes on it

    Alerts on every action and failure, logs you can read, and a write-up like the ones on this page.

FAQ

Common questions

What kind of projects are a good fit?

Anything repetitive where the data is a bit messy: categorizing, screening, summarizing, routing. If someone on your team does the same steps every week and hates it, that's usually a good fit.

Will an AI system make mistakes?

Yes, so I build for it. Every prediction carries a confidence score, low-confidence results go to a person, and the system logs what it did and why. You decide where the line for "trust it" sits.

Do I need to change the tools we already use?

Usually not. Most of my work reads from and writes to what you already have: QuickBooks exports, spreadsheets, a Telegram or Discord channel, your database.

Where do the systems run?

In Docker on whatever fits the job: GCP Cloud Run, a small VPS or your own server. You get the code and the deployment setup.

Do you work remotely?

Yes. I'm based in Puerto Rico and work with people anywhere. Calls are on Atlantic Time, which overlaps with US Eastern business hours.
